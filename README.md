# Tetőszerkezet

Tetőszerkezet szervezése.

A szarufa hosszát és a tető magasságát a ház szélességéből és a
tető dőlésszögéből számítható.

Tesztesetek:

| Ház szélessége | Dőlésszög | Szarufa | Tető magasság |
| - | - | - | - |
| 20 | 30 | 11.54 | 5.77 |
| 25 | 34 | 15.07 | 8.43 |
| 0 | 30 | hiba | hiba |
| 20 | 0 | hiba | hiba |
| 100 | 30 | hiba | hiba |
| 20 | 100 | hiba | hiba |

* A 50 méternél szélesebb épület nem lehet.
* A tető dőlésszöge maximum 70°
